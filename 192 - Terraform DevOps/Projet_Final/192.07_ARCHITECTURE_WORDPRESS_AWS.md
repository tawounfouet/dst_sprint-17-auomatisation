# 192.07 — Architecture WordPress AWS

## Vue d'ensemble

```text
Internet
   |
   v
Internet Gateway
   |
   v
Public subnet (AZ A)
   |
   +--> EC2 WordPress t3.micro
          |
          +--> EBS gp3 10 GiB
          |
          +--> TCP/3306 vers RDS

Private DB subnet (AZ A) ----+
                              +--> RDS MySQL db.t3.micro Multi-AZ
Private DB subnet (AZ B) ----+
```

## Modules

```text
root
├── networking
│   ├── VPC
│   ├── Internet Gateway
│   ├── public subnets
│   ├── private DB subnets
│   ├── route table
│   └── security groups
├── rds
│   ├── DB subnet group
│   └── MySQL Multi-AZ
├── ec2
│   ├── AMI dynamique
│   ├── instance WordPress
│   ├── IAM role
│   └── user_data
└── ebs
    ├── volume gp3 10 GiB
    └── attachment
```

## Sécurité

- HTTP 80 ouvert publiquement ;
- HTTPS 443 uniquement si activé ;
- SSH fermé par défaut ;
- RDS non public ;
- MySQL 3306 autorisé uniquement depuis le Security Group web ;
- mot de passe RDS géré par AWS Secrets Manager ;
- IAM EC2 limité à `secretsmanager:GetSecretValue` sur le secret concerné ;
- volumes racine EC2, EBS additionnel et stockage RDS chiffrés.

## Persistance

Le volume EBS supplémentaire est créé dans l'AZ réellement utilisée par l'instance EC2. Le bootstrap détecte ce second disque et le monte sur :

```text
/var/www/html/wp-content/uploads
```
