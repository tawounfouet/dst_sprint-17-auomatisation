# 191.07 — Troubleshooting et causes profondes

| Symptôme | Cause probable | Diagnostic | Correction |
|---|---|---|---|
| `UNREACHABLE` | SSH, IP ou utilisateur incorrect | `ssh -vvv`, `ansible -m ping -vvvv` | corriger inventaire/clé/réseau |
| `Access denied for user` | utilisateur MySQL, host ou secret erroné | test `mysql -h db1 ...` | vérifier Vault et `mysql_app_host` |
| `Can't connect to MySQL server` | bind-address ou firewall | `ss -ltnp | grep 3306` | écouter sur l’interface adaptée et ouvrir le flux privé |
| HTTP 403/404 | DocumentRoot ou permissions | logs Apache, `apache2ctl -S` | corriger vhost et ownership |
| HTTP 500 | extension PHP absente | logs Apache/PHP | installer l’extension requise |
| installer PrestaShop échoue | DB non prête ou paramètres incompatibles | relancer commande CLI manuellement | vérifier DB, PHP, version PrestaShop |
| secrets visibles | debug/log trop verbeux | inspection logs | `no_log: true`, éviter d’afficher les variables |

## Principe de diagnostic

Toujours descendre la pile : réseau → SSH → service → port → authentification → application.
