# 191.07 — Architecture du projet final

## Architecture logique

```text
                         ┌────────────────────────┐
                         │   Ansible control node  │
                         │ ansible-playbook       │
                         └───────────┬────────────┘
                                     │ SSH
                   ┌─────────────────┴─────────────────┐
                   │                                   │
                   ▼                                   ▼
        ┌─────────────────────┐             ┌─────────────────────┐
        │ web1                │             │ db1                 │
        │ groupe: web         │             │ groupe: database    │
        │ Apache :80          │             │ MySQL :3306         │
        │ PHP                 │             │ base prestashop     │
        │ PrestaShop          │────────────►│ user prestashop_app │
        └─────────────────────┘   SQL/TCP    └─────────────────────┘
```

## Flux

| Source | Destination | Port | Usage |
|---|---|---:|---|
| control node | web1 | 22 | Ansible/SSH |
| control node | db1 | 22 | Ansible/SSH |
| web1 | db1 | 3306 | accès applicatif MySQL |
| client | web1 | 80 | HTTP |

## Découpage des responsabilités

`mysql` ne déploie que la couche base de données. `prestashop` ne configure que le serveur web/PHP et l’application. `site.yml` orchestre l’ordre afin que la base existe avant l’installation applicative.

## Secrets

Les variables publiques et les secrets sont séparés entre `group_vars/all.yml` et un `group_vars/vault.yml` chiffré avec Ansible Vault.
