# Ansible — Core Images

Ce dossier accueillera les visuels génériques et canoniques utilisés par la documentation Ansible.

## Assets prévus

- logo ou visuel Ansible ;
- diagrammes d’architecture Ansible ;
- schémas control node / managed nodes ;
- diagrammes de workflow.

Les captures spécifiques à l’ancien setup AWS seront conservées séparément dans `resources/images/original-aws/` afin de ne pas les confondre avec le parcours Multipass actif.

Aucun asset contenant un secret, une adresse sensible ou des credentials ne doit être ajouté sans sanitisation préalable.
