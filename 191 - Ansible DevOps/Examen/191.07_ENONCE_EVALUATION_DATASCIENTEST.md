# 191.07 — Énoncé de l’évaluation DataScientest

> Ce document restructure le contenu de l’énoncé fourni dans le support de conclusion. Il n’ajoute pas d’exigence fonctionnelle absente de la source.

## Contexte

Vous intervenez comme ingénieur DevOps dans une startup e-commerce qui souhaite créer et déployer un nouveau site web.

## Objectif

Automatiser le déploiement de la solution retenue en créant **deux rôles Ansible distincts** :

- un rôle pour déployer Prestashop ;
- un rôle pour déployer une base de données MySQL.

Le serveur web doit pouvoir communiquer avec la base de données.

## Solution web

La solution de référence de l’énoncé est Prestashop.

Le support autorise toutefois une solution alternative, notamment Magento ou WordPress, si elle répond au besoin exprimé.

## Livrables

Le rendu doit être fourni sous forme d’une archive `.zip` contenant :

1. les deux arborescences de rôles correspondant aux besoins ;
2. le playbook permettant d’orchestrer l’exécution des rôles ;
3. les logs des résultats des tests dans un fichier `.txt` ;
4. des scripts pleinement fonctionnels, quel que soit l’environnement utilisé.

## Conseils de démarrage présents dans le support

Le support recommande de :

- commencer par construire l’inventaire ;
- prévoir un rôle par machine ;
- ouvrir le service HTTP sur le port `80` ;
- utiliser le port MySQL `3306` ;
- découper une architecture complexe en plusieurs rôles plutôt que d’écrire un playbook volumineux ;
- créer un utilisateur `root` pour la base de données afin que le serveur web puisse s’y connecter.

## Fin de l’évaluation

L’objectif est de démontrer l’autonomie sur Ansible en déployant une architecture plus complexe et en automatisant l’ensemble du processus.

Le support rappelle également de terminer les machines une fois le cours terminé.
