# 191.07 — Checklist de validation

## A. Structure

- [ ] un inventaire existe ;
- [ ] un groupe web existe ;
- [ ] un groupe database existe ;
- [ ] deux rôles distincts existent ;
- [ ] le rôle web possède une arborescence Ansible valide ;
- [ ] le rôle MySQL possède une arborescence Ansible valide ;
- [ ] un playbook principal orchestre les rôles.

## B. Connectivité Ansible

- [ ] `ansible-inventory --graph` fonctionne ;
- [ ] `ansible all -m ping` réussit ;
- [ ] aucun hôte n’est `UNREACHABLE`.

## C. Base de données

- [ ] MySQL est installé ;
- [ ] MySQL est démarré ;
- [ ] MySQL est activé au démarrage si prévu par le rôle ;
- [ ] la base applicative existe ;
- [ ] l’identité de connexion attendue existe ;
- [ ] la connexion depuis le serveur web est validée ;
- [ ] le port 3306 est traité conformément à l’architecture retenue.

## D. Serveur web

- [ ] la solution e-commerce retenue est installée ;
- [ ] les dépendances requises sont installées ;
- [ ] la configuration DB est injectée ;
- [ ] le serveur HTTP est actif ;
- [ ] le port 80 répond ;
- [ ] une requête HTTP retourne une réponse exploitable.

## E. Orchestration

- [ ] `ansible-playbook --syntax-check` réussit ;
- [ ] le play DB s’exécute ;
- [ ] le play Web s’exécute ;
- [ ] `failed=0` sur le scénario nominal ;
- [ ] `unreachable=0` sur le scénario nominal.

## F. Relance

- [ ] le playbook peut être relancé ;
- [ ] les changements résiduels sont compris ;
- [ ] aucune relance ne détruit une configuration déjà valide.

## G. Secrets

- [ ] aucune clé privée n’est versionnée ;
- [ ] aucun mot de passe réel n’est présent dans le dépôt public ;
- [ ] les secrets sont fournis via un mécanisme local/Vault dans l’implémentation réelle ;
- [ ] les fichiers de mot de passe Vault sont ignorés par Git.

## H. Preuves et livraison

- [ ] un fichier `.txt` contient les logs de tests ;
- [ ] les logs permettent d’identifier les commandes exécutées ;
- [ ] les deux rôles sont inclus dans le rendu ;
- [ ] le playbook d’orchestration est inclus ;
- [ ] les scripts nécessaires sont inclus ;
- [ ] le ZIP final peut être extrait et compris sans contexte externe implicite.
