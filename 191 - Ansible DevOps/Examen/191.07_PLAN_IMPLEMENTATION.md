# 191.07 — Plan d’implémentation

## Lot 0 — Préparer le projet

Créer l’arborescence de travail et l’inventaire.

```text
ansible-project/
├── ansible.cfg
├── inventory/
├── group_vars/
├── host_vars/
├── playbooks/
├── roles/
│   ├── prestashop/
│   └── mysql/
├── tests/
└── logs/
```

Critère de sortie : `ansible-inventory --graph` et `ansible all -m ping` fonctionnent.

## Lot 1 — Implémenter le rôle MySQL

Objectifs :

- installer MySQL ;
- démarrer et activer le service ;
- créer la base attendue par l’application ;
- préparer l’identité de connexion utilisée par le serveur web ;
- rendre les variables configurables ;
- protéger les données sensibles avec Vault dans l’implémentation réelle.

Critère de sortie : MySQL répond localement et les paramètres de connexion attendus existent.

## Lot 2 — Implémenter le rôle web

Solution de référence de l’énoncé : Prestashop.

Objectifs :

- installer les dépendances web nécessaires ;
- déployer l’application ;
- rendre la configuration DB paramétrable ;
- exposer le service HTTP sur le port 80 ;
- utiliser handlers/templates lorsque pertinent.

Critère de sortie : le serveur HTTP répond.

## Lot 3 — Orchestration

Créer le playbook principal.

```text
site.yml
├── play database
│   └── role mysql
└── play web
    └── role prestashop
```

Critère de sortie : `ansible-playbook --syntax-check` réussit puis l’exécution complète atteint un `PLAY RECAP` sans échec.

## Lot 4 — Validation d’intégration

Tester :

```text
control node → web
control node → db
web → db:3306
client → web:80
```

Critère de sortie : tous les flux nécessaires au scénario sont validés.

## Lot 5 — Relance et reproductibilité

Relancer le playbook complet et analyser `changed`, `ok`, `failed`, `unreachable`.

L’énoncé demande des scripts pleinement fonctionnels quel que soit l’environnement utilisé ; la mise en œuvre doit donc éviter au maximum les IP ou chemins propres à un poste.

## Lot 6 — Capturer les preuves

Créer un fichier texte contenant les logs de validation.

Exemples de commandes à capturer :

```bash
ansible-inventory --graph
ansible all -m ping
ansible-playbook site.yml --syntax-check
ansible-playbook site.yml
curl http://<WEB_HOST>
```

Ajouter un test de connectivité DB depuis le serveur web.

## Lot 7 — Produire le ZIP

Le rendu final doit contenir au minimum :

```text
roles/prestashop/
roles/mysql/
playbook principal
inventaire / exemples de configuration nécessaires
logs/tests.txt
scripts nécessaires
```

Avant archivage, vérifier l’absence de secrets en clair, de clés privées et de fichiers propres au poste local.

## Séquence globale

```text
inventory
   ↓
mysql role
   ↓
web role
   ↓
site.yml
   ↓
integration tests
   ↓
rerun
   ↓
logs.txt
   ↓
ZIP
```
