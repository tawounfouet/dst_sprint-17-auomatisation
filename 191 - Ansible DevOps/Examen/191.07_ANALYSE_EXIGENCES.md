## 2. Recommandations du support

Ces éléments sont formulés comme conseils de démarrage et non comme livrables autonomes :

- commencer par l’inventaire ;
- prévoir un rôle par machine ;
- découper la configuration en plusieurs rôles ;
- créer un utilisateur `root` pour permettre au serveur web de se connecter à MySQL.

Le dernier point est conservé comme conseil source dans l’énoncé. Dans l’implémentation de référence, toute divergence devra être documentée explicitement.

## 3. Exigences dérivées nécessaires à la démonstration

Les exigences suivantes sont des **déductions d’implémentation**, pas des phrases de l’énoncé :

| ID | Exigence dérivée | Justification |
|---|---|---|
| DER-01 | disposer d’au moins deux hôtes logiques | deux rôles / un rôle par machine |
| DER-02 | avoir un inventaire avec groupes web et DB | ciblage clair des rôles |
| DER-03 | disposer d’une configuration SSH valide | prérequis d’exécution Ansible |
| DER-04 | définir les paramètres DB utilisés par l’application | nécessaire à Web → MySQL |
| DER-05 | conserver les secrets hors du dépôt en clair | cohérent avec le chapitre Vault |
| DER-06 | produire un test de relance | vérifier le comportement répétable |
